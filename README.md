# Многопроцессный симулятор морского порта

Я написал на C модель порта для Linux. Суда, буксиры, краны и склады работают как отдельные процессы. Диспетчер продвигает модельное время и распределяет ресурсы. Для общей модели использую разделяемую память POSIX, для синхронизации — семафоры.

## Сборка и запуск

```sh
make
./port_sim_unnamed --seed=42 --unlimited --delay-us=10000
./port_sim_named --seed=42 --unlimited --delay-us=10000
bash run_independent.sh --seed=42 --unlimited --delay-us=10000
make test
```

Я реализовал три варианта запуска.

- `port_sim_unnamed` создаёт процессы через `fork` и использует неименованные семафоры в общей памяти.
- `port_sim_named` создаёт процессы через `fork` и использует именованные семафоры.
- `port_sim_independent` и `port_worker` запускаются независимо, используют именованные семафоры и общую память. Роли можно запустить вручную или через `run_independent.sh`.

Список параметров доступен через `./port_sim_unnamed --help`. Журнал записывается в `port.log`. Для остановки можно нажать Ctrl+C. Объекты POSIX имеют фиксированные имена, поэтому одновременно запускай один экземпляр симуляции.

Тесты проверяют логику диспетчера, полный прогон в каждом режиме, остановку по сигналу и освобождение объектов IPC.
